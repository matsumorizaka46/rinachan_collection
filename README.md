# 松田里奈 生写真管理ツール 🌸

櫻坂46 松田里奈ちゃん向けに開発された、生写真所持状況・コンプ率・トレード管理を行うためのブラウザ完結型Webアプリケーションです。

---

## 🌺 主な機能

- **全生写真一覧・所持管理**
  - 欅坂46・櫻坂46の歴代衣装、封入、限定生写真を網羅。
  - ポーズ別（ヨリ・チュウ・座り・ヒキ）の所持枚数を簡単に記録できます。
  - 「一括✓」ボタンで全ポーズをワンタップで所持状態にすることが可能です。
- **高画質画像アップロード**
  - ご自身で撮影・お持ちの写真を各ポーズに登録できます（画質を落とさずそのままブラウザ内に保存されます）。
- **未所持生写真一覧**
  - まだコンプしていない、あるいは持っていないポーズが一目でわかる一覧表示。
- **トレード管理＆SNS用文章自動生成**
  - 求める生写真にチェックを入れて「トレード文を生成」を押すだけで、X（旧Twitter）等のトレード募集用テンプレート文を自動作成。
  - 作成したトレード表をそのまま画像としてダウンロード・保存も可能です。
- **トレード予定管理**
  - 取引相手、提供品・頂くもの、取引方法（郵送・現地など）を登録・管理し、完了した取引を整理できます。

## ⚠️ ご利用前の重要な注意事項（データ保存について）

本ツールは**サーバーへのデータ送信を一切行いません**。
登録された所持枚数、アップロードされた画像、トレード予定などのデータは、すべて**ご利用のブラウザ内（LocalStorage）にのみ保存**されます。

- **データの消失について**
  ブラウザのキャッシュ削除、プライベートブラウジングモードの使用、端末の変更などにより、保存されたデータが消えてしまう場合があります。
- **定期的なバックアップのお願い**
  大量のデータを登録した際や、定期的に画面右上の**「データバックアップ」**ボタンからテキストコードをコピーし、メモアプリ等に保存してください。
  万が一データが消えた場合も、**「バックアップを復旧」**ボタンから保存したコードを貼り付けることでいつでも元の状態に戻すことができます。

---

## 🌴 使い方

1. サイトを開くと初回に注意事項のポップアップが表示されます。内容をご確認の上、利用を開始してください。
2. 「全生写真一覧」タブからお持ちの生写真の枚数を `＋` / `-` ボタンで記録します。
3. 必要に応じて「トレード管理」から交換を募集したい生写真を選択し、SNS用の文章や画像を生成します。
4. こまめに「データバックアップ」を行い、データを保護してください。
